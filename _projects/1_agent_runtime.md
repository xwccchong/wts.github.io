## Overview

Participated in the development of a robot intelligence platform for embodied AI agents. Built a unified **AgentRuntime** that abstracts robot capabilities (navigation, manipulation, vision) behind standardized skill interfaces, enabling the same hardware and codebase to rapidly deploy across robot dogs, robotic arms, and mobile manipulators.

## Key Contributions

- **AgentRuntime Architecture:** Designed the core architecture abstracting navigation, manipulation, and vision capabilities into unified skill interfaces with dynamic scheduling.
- **Standardized Deployment:** Built a standardized Jetson-based runtime environment, enabling plug-and-play integration of diverse robot platforms including quadruped robots, Franka robotic arms, and compound mobile manipulators.
- **Cross-Robot Coordination:** Enabled cooperative task execution across heterogeneous robots through unified skill orchestration.
