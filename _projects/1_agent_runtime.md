## Overview

Contributed to a robot intelligence platform for embodied AI agents. The platform exposes navigation, manipulation, and perception through a unified **AgentRuntime** and standardized skill interfaces, allowing a shared codebase to be deployed across quadrupeds, robotic arms, and mobile manipulators.

## Key Contributions

- **AgentRuntime Architecture:** Designed the core runtime architecture, defining unified skill interfaces for navigation, manipulation, and vision with dynamic scheduling.
- **Standardized Deployment:** Built a standardized Jetson-based runtime environment for plug-and-play integration of quadrupeds, Franka arms, and mobile manipulators.
- **Cross-Robot Coordination:** Supported coordinated task execution across heterogeneous robots through reusable skill orchestration.
